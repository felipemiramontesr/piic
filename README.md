## 🚀 Engine Status: Silicon Valley Pinnacle Standard

Este proyecto ha sido elevado a un estándar de ingeniería de clase mundial, eliminando toda deuda técnica y estableciendo una base de desarrollo de "Zero-Noise".

### ✨ Key Features

- **🛡️ 100% Unit Test Coverage**: Suite exhaustiva con `Vitest` y `React Testing Library`, asegurando integridad total en formularios complejos y lógica de negocio.
- **📚 Storybook Component Lab**: Documentación visual e interactiva de todos los componentes atómicos (`WhatsAppPill`, `LanguageSwitcher`, forms, etc).
- **🌍 Advanced Localization**: Sistema i18n binario (ES/EN) con persistencia de estado y detección automática.
- **📱 PWA Certified**: Instalable en dispositivos móviles con arquitectura Ready-to-Offline.
- **🏗️ Documented Architecture**: Diagramas Mermaid y `ARCHITECTURE.md` para onboarding inmediato.
- **⚡ Zero-Weight Assets**: Branding basado en componentes CSS/SVG optimizados, reduciendo el LCP (Largest Contentful Paint).

## 🛠️ Tech Stack

- **Frontend**: React 18 / Vite 5
- **Testing**: Vitest + @testing-library/react + c8/v8 Coverage
- **Docs**: Storybook 8
- **Styles**: Vanilla Modern CSS + Responsive Framework
- **Backend**: PHP 8 (Mail Handlers) / Rate-Limited API

## 🧑‍💻 Development

### Quality Commands

```bash
# Ejecutar tests y verificar cobertura del 100%
npm run test:coverage

# Formatear código (Silicon Valley Coherency)
npm run format

# Ejecutar Storybook localmente
npm run storybook

# Build de producción
npm run build
```

## 📁 Project Structure

- `src/components`: UI Elements atómicos.
- `src/sections`: Bloques funcionales de la Landing.
- `src/pages`: Páginas secundarias y cuestionarios.
- `src/locales`: Diccionarios de traducción.
